# 소스 커버리지·Apple 분기 확장 결과

[영문 문서](COVERAGE_RESULTS.md)가 원본이다. [이전 보강 결과](HARDENING_RESULTS.ko.md) ·
[재평가 JSON](results/2026-10-09-public-coverage-extension.json) ·
[실행·리뷰 근거](results/2026-10-09-coverage-evidence.json).

선택한 Kotlin/Swift 문법 누락을 복구하고, 인식한 함수 커버리지를 공개하며,
근거가 갖춰진 Apple CNA 분기 판정을 추가했다. 고정한 공개 앱 소스 6개 모두
검사를 완료했지만, 6개 모두 감사 범위는 여전히 불완전하다.
**정답을 확인한 뒤 수행한 개발 재평가**로, 새로운 독립 검증 집합이나 앱 전체
보안 평가, 일반 정확도 추정이 아니다.

규칙은 미배포 후보 `2026.10.09.apsa.111-dev3`다. 패키지 메타데이터는
`1.1.0`이며, 배포된 PyPI 1.1.0 결과가 아니다. 변경은
`hardening/real-app-cve-v1` 브랜치에 반영했다.

## 소스 측정

아래는 **이번 재평가 안에서** 원래 파서와 호환 처리 후 파서를 비교한 값이다.
이전 dev2 요약에는 함수 수가 없었다. 함수는 AST에서 인식한 함수 노드이며,
클로저와 초기화 구문은 집계하지 않는다.

| 고정 앱 | 원래 → 남은 오류 파일 | 호환 처리 파일 | 원래 → 최종 인식 함수 | 분석 / 건너뜀 / 본문 없음 |
| --- | ---: | ---: | ---: | ---: |
| NewPipe | 0 → 0 | 0 | 4,735 → 4,735 | 4,471 / 0 / 264 |
| AntennaPod | 0 → 0 | 0 | 4,576 → 4,576 | 4,404 / 0 / 172 |
| K-9 Mail | 6 → 2 | 4 | 11,526 → 11,625 | 10,925 / 1 / 699 |
| Nextcloud iOS | 0 → 0 | 0 | 2,369 → 2,369 | 2,369 / 0 / 0 |
| Firefox iOS | 78 → 66 | 14 | 26,885 → 26,885 | 26,844 / 41 / 0 |
| Ice Cubes | 2 → 2 | 0 | 1,037 → 1,037 | 1,035 / 2 / 0 |

K-9에서 함수 99개를 추가로 인식했다. Kotlin 파일 4개와 Swift 파일 14개를
호환 처리했으며, Swift 파일 2개는 처리 후에도 오류가 남는다. 따라서 파일
16개의 원래 구문 오류가 해소됐다. 새 보안 정탐 수를 측정하거나 전체 함수
커버리지를 입증한 결과는 아니다.

Kotlin은 소프트 키워드 `open`이 식별자로 쓰인 경우 파서 입력 바이트만 바꾼다.
Swift는 직접 이어지는 `var` 또는 `let` 앞의 정확한 미지원
`nonisolated(unsafe)` 구문만 공백으로 처리한다. 둘 다 바이트 위치를 유지하고,
근거는 원래 소스에서 읽는다. 호환 처리한 파일은 **항상 부분 분석으로 남고**
기존 패턴 규칙의 제외 근거를 만들 수 없다. 동시성 의미는 모델링하지 않는다.

CLI/MCP 커버리지와 `inventory.source_analysis`에 인식·분석·건너뜀·본문 없는
함수 수, 원래 파서 오류와 호환 처리 정보를 노출한다. 분석하지 못한 파일의
함수 목록은 null로 유지한다. 건너뛴 함수가 0개여도 모든 호출 가능 구문을
인식했다는 뜻은 아니다. 미지원 언어·파서 오류·예산 제한으로 함수를 놓칠 수
있다. 여기서는 AntennaPod만 인식 함수 목록을 complete로 표시하지만, 앱 전체
감사는 여전히 불완전하다.

앱별로 세 번 검사했고 채점한 관찰값과 탐지 근거가 안정적으로 유지됐다.
요약에 파싱하지 못한 대상 레코드나 남은 소스 레코드는 없지만, 미지원 언어의
커버리지는 별개로 남는다.

## Apple 분기 판정

Apple 할당기관·CNA 제공기관 식별자, Apple 제품, 지원하는 iOS/iPadOS 별칭,
공유하는 공식 Apple 공지 URL, 관찰한 메이저 버전의 단일 0 기반 custom 상한,
정확히 일치하는 수정 릴리스 이름이 모두 필요하다. 다른 custom 범위는 판단을
유보한다. 기존 캐시에 기관 식별자가 없으면 CVE를 다시 받아야 이 경로가 적용된다.

[추가 사례 14개](ios_branch_cases.json)는 **CVE-2025-24201 하나**를 다룬다.
Apple 링크의 릴리스 이름을 확인한 합성 환경·벤더 레코드다. 새로 수집한 HTTP
응답 바이트나 실제 기기, 서로 독립적인 취약점 14개가 아니다.

| 기대 분류 | 일치 |
| --- | ---: |
| 공개한 분기의 영향 범위 | 4 / 4 |
| 공개한 분기의 영향 범위 밖 | 5 / 5 |
| 적용 여부 불명 | 4 / 4 |
| 시뮬레이터만 해당 | 1 / 1 |
| 합계 | 14 / 14 |

확인한 경계는 [iOS 15.8.4](https://support.apple.com/en-us/122345),
[iOS 16.7.11](https://support.apple.com/en-us/122346),
[iOS 18.3.2](https://support.apple.com/en-us/122281),
[iPadOS 17.7.6](https://support.apple.com/en-us/122372)다. iPadOS 전용 근거에는
`os_product: "ipados"`를 명시해야 하며 기본값은 iOS다. 다른 메이저 버전,
베타 이름, 맞지 않는 공지나 누락된 제품 근거는 판단을 유보한다.
양성 탐지는 후보 상태이며 앱 도달성은 불명이다. 공개 영향 범위 밖이라는
판정은 패치 설치나 기기 안전성을 입증하지 않는다.

**기존 OS 사례 11개의 기대 상태는 변경하지 않았다.** 고정 정답과의 일치는
이제 **9/11**이다. 기존 판단 불가 iOS 사례 두 개가 의도한 새 판정으로 바뀌기
때문이다. iOS 18.3.1은 `version-affected`, 18.3.2는
`outside-published-affected-range`가 된다. 나머지 9개 상태는 그대로다.
추가 사례 점수는 별도이며, 11/11로 만들려고 기존 정답을 수정하지 않았다.

## 회귀 검증·재평가·리뷰

선택한 설정 사실은 6/6, 의존성 선언은 10/10을 유지했다. 기존 의존성·CVE
32개 단위는 정탐 8, 오탐 0, 미탐 0, 진음성 19, 올바른 유보 5개를 유지했다.
선택한 실제 앱 경로는 정탐 1, 진음성 3개다. AntennaPod jsoup 탐지는 선언된
소스 근거·후보 상태·도달성 불명을 유지하며, 이전에 고정한 별도 시점 보충
응답을 재사용한다. 이 선별 점수로 일반적인 운영 정확도를 입증하지 않는다.

[재평가 37889988853](https://github.com/ictechgy/apsa/actions/runs/37889988853)은
공개 커밋 `3da9b8a99c14b638040c4361bb567fdd34453b6c`에서 성공했다.
로컬 리뷰 헤드 `f5c05db5c271805c518979454bf3673c035ff439`와 동일한 트리
`18bf3101701d3a894ea3506936229e82a307a663`다.
입력 ZIP 6개, 원래 정답, 기존 OSV 응답 29개와 유지한 jsoup 보충 응답 하나를
재사용했다. 새 OSV 수집은 없었다. 과거 결과 파일 두 개의 바이트도 동일하며,
해시와 매니페스트 해시는 근거 JSON에 기록했다.

아티팩트 `11598057271`, `public-coverage-replay`에는 공개 입력, 고정 응답과
재평가 보고서가 들어 있다. 다이제스트는
`sha256:e96ffe7ccce1491760ff9f53b344e69b1232b8e9727e745da603a902cc78e005`,
만료는 `2026-11-08T05:46:04Z`다. 완전한 오프라인 재현에는 만료 전에 공개
입력 아티팩트를 보존해야 한다. 커밋한 결과는 출력된 coverage JSON을 파싱해
하네스의 정렬·들여쓰기 형식으로 저장한 파일이며 SHA-256은
`499910bb95bbb25bd596a235ec571dfe98f853906f3aa094e1e01a554880267d`다.
이는 아티팩트 다이제스트와 별개다.

[CI 37889988833](https://github.com/ictechgy/apsa/actions/runs/37889988833)은
Linux/macOS × Python 3.11/3.12 네 환경에서 **832개 테스트**, Ruff, Pyright,
독립 코퍼스, 반복 빌드, 출처 고지, 깨끗한 오프라인 설치·CLI·MCP·패키지 스킬
검사를 통과했다. [코드·명세·보안 리뷰](reviews/2026-10-09-coverage-code.md)는
`APPROVE`, [설계 리뷰](reviews/2026-10-09-coverage-architecture.md)는 `CLEAR`를
위 전체 구현 스냅샷에 반환했다. 독립 Codex 리뷰이며 Claude·Devin·Agy 실행은 아니다.

## 남은 근거

이후 [추가 분석·독립 정답 평가](NEXT_RESULTS.ko.md)는 다른 배포 전 스냅샷에서
아래 누락 일부를 다룹니다. 이 문서는 dev3 측정·리뷰 범위를 보존하며 새 파서,
Objective-C·catalog 사용 판정을 설명하지 않습니다.

Kotlin 생성자·줄바꿈과 최신 Swift `@Sendable`, `if await` 등 구문 누락이
남아 있다. Firefox의 큰 PBX 참조 토큰 예산과 Deferred plist 누락·유효성 경고도
남는다. Objective-C 등 미지원 언어, 빌드 변형, AAB/IPA 내장 바이너리, 기기
시험과 OS 샌드박스 동작은 별도로 평가해야 한다. 업스트림 앱·빌드 스크립트·
백엔드·기기를 실행하지 않았고 MobSF도 다시 평가하지 않았다.

일반 정확도나 경쟁력 주장 전에는 새로 독립 라벨링한 앱·CVE 사례가 필요하다.
미공개 제로데이, 피드 완전성이나 앱 전체 악용 가능성을 채점하지 않았다.
이번 작업으로 main을 합치거나 릴리스를 만들거나 패키지 저장소에 배포하지 않았다.

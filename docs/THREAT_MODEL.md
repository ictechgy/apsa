# APSA (앱사) 보안 경계

검사 대상은 사용자가 검사 권한을 가진 앱의 소스·빌드·테스트 기기입니다. 보호할 정보는 앱 코드와 바이너리, 테스트 계정 정보, canary, 기기 캡처, 보고서와 인텔 출처, 모델 클라이언트 인증 정보입니다.

## 데이터 흐름과 신뢰 경계

로컬 CLI/TUI → 유한 파서 프로세스 → 로컬 보고서 저장소가 정적 검사의 기본 흐름입니다. 공식 피드 수집기는 공개 문서를 받아 같은 저장소의 인텔 캐시를 갱신합니다. 런타임 어댑터는 명시한 테스트 앱·기기의 상태를 바꾸고 제한된 증거를 수집합니다. MCP는 이 엔진의 결과를 호출한 모델 클라이언트에 전달합니다.

| 입력·경계 | 예상 위험 | 구현과 실제 제한 |
| --- | --- | --- |
| 소스·APK/IPA·SBOM·설정 | 경로 이탈, ZIP 폭탄, 과도한 메모리·출력, 파서 충돌 | 심볼릭 링크를 따르지 않는 읽기, 선언된 MCP 루트, 아카이브 내 경로·크기 검증, 원본 트리에 추출하지 않음. 바이너리는 안정된 임시 복사본을 해석. 시간·CPU·RSS·출력·파일 수 제한과 종료 처리가 있음 |
| 파서 프로세스 | 원본 입력의 취약점이 라이브러리 결함을 유발 | 프로세스와 자원 경계는 크래시·고갈을 제한함. OS 권한을 낮추는 샌드박스가 아니므로 파서 코드 실행 취약점의 파일 접근·네트워크 접근까지 차단하지 않음 |
| 피드·CVE·OSV 응답 | 크기 초과, 잘못된 형식, 버전 오판, 출처·수정 이력 손실 | 스트리밍 한도·구조 검증·공식 출처 제한, 별도 공급사 branch, 내용 해시별 revision, 실패 시 기존 캐시 유지·재시도·보류 수 표시. 공개 기록의 사실 자체나 공급사 backport 적용 여부를 보증하지 않음 |
| 보고서·기준 보고서 | 덮어쓰기, 다른 앱 기준으로 문제 은폐, 만료 예외 | 변경 불가능한 ID별 보고서, 부모 연결, DB/JSON 무결성 검사, 앱 식별자/대상 확인, 증거 강화 재개, 만료 예외는 불완전 판정. 해시는 발행자 서명이 아니며 같은 사용자 권한으로 DB와 해시를 함께 바꾸는 공격자는 범위 밖 |
| 테스트 기기 | 다른 앱 UI 혼입, 잘못된 빌드, 전환 없는 삭제 통과 | 앱 식별자·설치 버전·APK 또는 IPA 실행 파일/Info.plist 해시 확인, 기기별 실행 잠금, Android 앱 범위 UI, baseline·전환·전달 assertion 분리. 해시 확인 이후에 다른 도구가 기기를 바꾸지 않는 운영 조건이 필요 |
| MCP·모델 | 과도한 파일 권한, 프롬프트 인젝션, 비밀 전달 | 반복 가능한 `--root`, 기기 실행 `--allow-runtime` 및 실행 플래그, 공개 context의 코드 excerpt·저장소 원문·canary 값 제외. 앱·공지 텍스트는 명령이 아닌 데이터로 안내. 모델 클라이언트의 자체 파일 도구·외부 전송 정책까지 제품이 통제하지 않음 |

macOS는 XNU의 `O_NOFOLLOW_ANY`로 입력 디렉터리의 조상 링크도 거부합니다. Linux는 디렉터리 descriptor를 따라 각 구성 요소를 `O_NOFOLLOW`로 엽니다. macOS 시스템의 `/tmp` 같은 링크 경로는 호출 경계에서 정규화한 경로를 사용해야 합니다. 세부 구현 근거는 [XNU fcntl.h](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/fcntl.h)입니다.

## 저장과 외부 연결

앱 소스·APK/IPA를 취약점 피드 제공자에게 업로드하지 않습니다. 오프라인 스캔은 네트워크를 호출하지 않고 문법 라이브러리도 실행 중 내려받지 않습니다. 초기 의존성 설치에는 패키지 저장소가 필요할 수 있습니다. 온라인 OSV 조회는 발견한 의존성 이름·생태계·버전을 전송합니다. 소스 공개 여부는 이 데이터 흐름과 별개입니다.

MCP 결과는 앱 식별자·파일 위치·함수/메서드명·의존성·환경·검사 결과를 포함합니다. 연결한 클라이언트가 hosted 모델을 사용하면 이 메타데이터도 외부로 전달될 수 있습니다. 원본 저장소 접근을 가진 모델의 별도 파일 도구까지 막아 주는 장치는 아닙니다. 인증은 클라이언트가 담당하며 제품에 모델 API 키를 저장하지 않습니다.

시나리오의 canary 값은 실행할 로컬 파일과 백그라운드 작업의 비공개 payload에 존재할 수 있습니다. 보고서는 값 대신 label·파일 해시·발견 위치를 기록합니다. 요청한 스크린샷은 민감한 화면을 포함할 수 있으며 로컬에 저장합니다. 홈 디렉터리·DB·작업 payload·캡처의 보관과 백업은 [운영 가이드](OPERATIONS.md)의 책임 범위입니다.

## 판정의 한계

정적 후보와 설정, 버전 영향과 런타임 관찰은 구분합니다. 공개 전 제로데이, 전체 MASVS 인증, 서버의 토큰 폐기, 모든 native/암호화 코드, 실제 iOS 기기·Keychain·clipboard 전체 검증은 제공하지 않습니다. iOS simulator의 UI/로그는 미실행으로 남습니다. 누락·실패·한도 초과·관찰되지 않은 baseline은 통과 증거가 아닙니다. 공식 피드도 폴링·공개 시점과 보류 큐 때문에 지연될 수 있습니다.

회귀 검사는 경로·자원 제한, 보고서 변조와 이전, 루트 밖 MCP 작업, 잘못된 baseline·waiver, UI 혼입, 누락된 capture, 상태 전환과 설치 빌드 연결을 다룹니다. 실제 환경별 증거는 [지원 표](SUPPORTED_MATRIX.md)와 [릴리스 검증 상태](../RELEASE_READINESS.md)에 기록합니다.
